# TUGAS HTML DASAR - Tutorial WPU

## 📚 Deskripsi

Repository ini berisi tugas untuk belajar HTML dasar berdasarkan playlist tutorial dari Web Programming UNPAS (WPU) video 1-13.

## 🎯 Tujuan Pembelajaran

Setelah menyelesaikan tugas ini, kamu diharapkan dapat:
- Memahami struktur dasar HTML
- Menggunakan berbagai tag HTML dengan benar
- Membuat website multi-halaman dengan navigasi
- Membuat tabel dengan berbagai konfigurasi
- Membuat form dengan berbagai tipe input

## 📁 File dalam Repository

1. **TUGAS_HTML.html** - Dokumen lengkap yang berisi instruksi tugas
2. **TEMPLATE_TUGAS.html** - Template contoh yang bisa dijadikan referensi
3. **index.html** - File Text-to-Speech app (proyek sebelumnya, bisa diabaikan untuk tugas ini)

## 🚀 Cara Memulai

1. Baca file `TUGAS_HTML.html` dengan membukanya di browser
2. Lihat `TEMPLATE_TUGAS.html` untuk referensi struktur HTML
3. Buat folder baru untuk tugas kamu: `TugasHTML_NamaKamu`
4. Buat 3 file HTML:
   - `index.html` (Halaman Beranda)
   - `pendidikan.html` (Halaman Riwayat Pendidikan)
   - `kontak.html` (Halaman Kontak & Formulir)
5. Kerjakan sesuai kriteria yang ada di dokumen tugas

## 📋 Checklist Pengerjaan

### Halaman 1: index.html
- [ ] Heading h1, h2, h3
- [ ] Foto/gambar
- [ ] Minimal 3 paragraf
- [ ] List (ul atau ol)
- [ ] Link navigasi ke halaman lain

### Halaman 2: pendidikan.html
- [ ] Heading
- [ ] Tabel riwayat pendidikan (minimal 3 baris)
- [ ] Table header dengan thead
- [ ] List keahlian
- [ ] Link navigasi
- [ ] BONUS: Colspan atau rowspan

### Halaman 3: kontak.html
- [ ] Heading
- [ ] Informasi kontak
- [ ] Form dengan input text
- [ ] Form dengan input email
- [ ] Form dengan radio button
- [ ] Form dengan checkbox
- [ ] Form dengan select/dropdown
- [ ] Form dengan textarea
- [ ] Button submit
- [ ] Link navigasi

## 💡 Tips

- Jangan terburu-buru, kerjakan step by step
- Review video tutorial jika lupa
- Test di browser setelah setiap perubahan
- Pastikan semua link berfungsi
- Buat indentasi yang rapi
- JANGAN gunakan CSS atau JavaScript dulu

## 📦 Cara Pengumpulan

1. Buat folder: `TugasHTML_NamaKamu`
2. Simpan semua file HTML di folder tersebut
3. Jika ada gambar lokal, simpan di subfolder `images/`
4. Compress menjadi ZIP
5. Kirim ke kakak
