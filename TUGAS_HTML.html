TUGAS AKHIR: HTML DASAR

Berdasarkan Tutorial WPU (Video 1-13)

INSTRUKSI UMUM:

Buatlah sebuah website sederhana tentang DIRI SENDIRI (Personal Website) yang mencakup SEMUA elemen HTML yang telah dipelajari dari video tutorial.

Website harus terdiri dari MINIMAL 3 HALAMAN yang saling terhubung menggunakan hyperlink.

KRITERIA TUGAS:

Halaman 1: Beranda (index.html)

Halaman ini harus berisi:

  • Judul halaman menggunakan <h1>
  • Foto diri menggunakan <img> (bisa foto asli atau gambar placeholder)
  • Paragraf perkenalan diri (minimal 3 paragraf) menggunakan <p>
  • Sub-judul menggunakan <h2> dan <h3>
  • List hobi atau kegemaran (ordered list atau unordered list)
  • Link navigasi ke halaman lain (Pendidikan & Kontak)

Halaman 2: Riwayat Pendidikan (pendidikan.html)

Halaman ini harus berisi:

  • Judul halaman menggunakan <h1>
  • Tabel riwayat pendidikan dengan kolom:
    • Tahun
    • Jenjang Pendidikan
    • Nama Sekolah/Universitas
    • Kota
  • Tabel harus memiliki minimal 3 baris data
  • Gunakan <thead> untuk header tabel
  • BONUS: Gunakan table merging (colspan atau rowspan) untuk membuat tabel lebih menarik
  • List keahlian atau skill yang dimiliki
  • Link navigasi kembali ke halaman lain

Halaman 3: Kontak & Formulir (kontak.html)

Halaman ini harus berisi:

  • Judul halaman menggunakan <h1>
  • Informasi kontak dalam bentuk list atau tabel:
    • Email
    • Nomor Telepon
    • Media Sosial (dengan link menggunakan <a>)
  • Formulir kontak dengan minimal:
    • Input text untuk Nama
    • Input email untuk Email
    • Textarea untuk Pesan
    • Radio button untuk memilih topik (misal: Pertanyaan, Saran, Kerjasama)
    • Checkbox untuk berlangganan newsletter
    • Select/Dropdown untuk memilih cara dihubungi (Email/Telepon/WhatsApp)
    • Button submit
  • Link navigasi kembali ke halaman lain

CHECKLIST ELEMEN YANG HARUS ADA:

Pastikan website kamu menggunakan SEMUA elemen berikut:

  1. ✓ <!DOCTYPE html> dan struktur HTML yang benar
  2. ✓ <head> dengan <title> yang sesuai
  3. ✓ <h1> sampai <h3> (minimal)
  4. ✓ <p> untuk paragraf
  5. ✓ <ul> atau <ol> dengan <li>
  6. ✓ <a href=""> untuk link internal antar halaman
  7. ✓ <a href=""> untuk link eksternal (misal: media sosial)
  8. ✓ <img src="" alt=""> untuk gambar
  9. ✓ <table> lengkap dengan <thead>, <tbody>, <tr>, <th>, <td>
  10. ✓ <form> dengan berbagai input type
  11. ✓ <input type="text">
  12. ✓ <input type="email">
  13. ✓ <input type="radio">
  14. ✓ <input type="checkbox">
  15. ✓ <textarea>
  16. ✓ <select> dengan <option>
  17. ✓ <button> atau <input type="submit">
  18. ✓ <hr> untuk garis pemisah
  19. ✓ <br> untuk line break (jika diperlukan)
  20. ✓ <strong> atau <b> untuk teks tebal

TIPS PENGERJAAN:

  • Gunakan code editor yang sudah dipelajari (VS Code, Sublime Text, atau Notepad++)
  • Beri nama file dengan benar: index.html, pendidikan.html, kontak.html
  • Pastikan semua link berfungsi dengan baik
  • Jika tidak ada foto, gunakan placeholder image dari: https://via.placeholder.com/300
  • Indentasi kode dengan rapi agar mudah dibaca
  • Test website di browser sebelum dikumpulkan
  • JANGAN menggunakan CSS atau JavaScript dulu, fokus ke HTML saja

BONUS (OPSIONAL):

Untuk mendapatkan nilai lebih, kamu bisa menambahkan:

  • Halaman tambahan (misal: Galeri, Portfolio, Blog)
  • Tabel dengan colspan atau rowspan yang kompleks
  • List bersarang (nested list)
  • Link ke file eksternal (misal: CV dalam format PDF)
  • Elemen <blockquote> untuk quote favorit
  • Elemen <code> atau <pre> untuk menampilkan kode

CARA PENGUMPULAN:

  1. Buat folder dengan nama: TugasHTML_NamaKamu
  2. Simpan semua file HTML di dalam folder tersebut
  3. Jika menggunakan gambar lokal, simpan di folder images/ di dalam folder tugas
  4. Compress folder menjadi ZIP
  5. Kirim file ZIP kepada kakak
